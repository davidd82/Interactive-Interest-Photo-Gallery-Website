# Interactive Interest & Photo Gallery Website

A multi-page responsive website built with HTML and CSS featuring an interactive interest page, image gallery, 
flexbox layouts, hover effects, custom fonts, and dropdown navigation menus.

---

## Project Overview

This project was developed across multiple assignments to demonstrate front-end web development concepts including responsive 
layouts, navigation systems, image galleries, typography customization, and interactive UI effects.

The website includes:
- A homepage focused on a personal hobby or interest
- A responsive sidebar layout using Flexbox
- A separate image gallery page
- Interactive hover captions and overlays
- A dropdown navigation menu
- Custom typography using local and Google Fonts

---

## Features

### Homepage
- Header with background image and title
- Multiple content sections with headings and paragraphs
- Responsive two-column Flexbox layout
- Sidebar with images and hover captions
- Hyperlinks and formatted lists
- Navigation bar with hover effects
- Footer section with consistent styling

### Gallery Page
- Unique header image and title
- Creative collage-style image layout
- Responsive image blocks with proportional scaling
- Overlay captions displayed on hover
- Consistent spacing and styling throughout the page

### Interactive UI Features
- Dropdown navigation menu
- Hover animations and image overlays
- Dynamic caption visibility
- Responsive layouts using Flexbox
- Custom typography and spacing
